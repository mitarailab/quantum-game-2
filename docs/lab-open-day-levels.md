# 2026年11月2日 研究室公開向けのステージ調整

日本語版2.2.18では、攻略資料の検証で見つかった設定と判定を調整した。

- 16：現行の糖溶液は1回45度回転する。固定偏光子を損失なく通過させる9個を用意するため、道具箱に2個追加。
- 20・35：光子源の偏光値は回転数の単位。旧値90は90度ではなく90回転として解釈されて水平偏光になっていた。この2問だけ0.25（90度、垂直偏光）へ変更。
- 33：鏡1枚を道具箱へ追加。光を(10,2)で折り返すことで、ファラデー回転子を往復利用した後に検出器へ戻す配置を用意できる。旧設定が不可能であるという証明はしていない。
- 勝利判定：計算上25%となる確率が0.2499999999999999になって失敗するため、検出器と地雷の比較に1e-12の数値誤差を許容。課題の目標確率は保持。

修正した4問の解答を `scripts/fixtures/lab-open-day-solutions.json` に記録し、`npm run test:campaign` で実エンジンの50ステップ計算、工具数、固定部品、目標の保持と勝利を確認する。境界判定では微小な丸め誤差を許容し、意味のある不足や地雷への確率は失敗となることも確認する。

他のステージの盤面設定は変更していない。
